# Monitoria de Engenharia de Software I (IFPR Pinhais)

Sou o Ciro Guilherme Nass, aluno do 4º ano de Ciência da Computação no IFPR Campus Pinhais. Em 2026 faço monitoria voluntária em Engenharia de Software I, com orientação da Profa. Lauriana Paludo. Na disciplina, atuo com a turma de BCC em sala de aula e no laboratório: tiro dúvidas, apoio a professora nas atividades práticas e acompanho as equipes do projeto integrador. A monitoria está ligada ao projeto de extensão DevOps Azure IFPR (SUAP 1810/2024), que oferece minicursos abertos ao público.

Este repositório junta o material que uso na monitoria e serve de canal de atendimento. Qualquer pessoa pode usar e perguntar, sendo aluna do IFPR ou não.

## Como tirar uma dúvida

Abra uma [issue](../../issues/new/choose) explicando o que você tentou fazer, o que aconteceu e, se tiver, a mensagem de erro ou um print. Basta ter uma conta no GitHub.

Respondo em até 2 dias úteis. Se a dúvida for de outras pessoas também, a resposta fica pública na issue e serve para quem vier depois.

Alunos da disciplina também podem combinar atendimento presencial ou por Meet pelo grupo da turma.

## Assuntos que eu atendo

- Testes e integração contínua com GitHub Actions

- Dúvidas sobre os guias dos minicursos do projeto DevOps Azure IFPR
