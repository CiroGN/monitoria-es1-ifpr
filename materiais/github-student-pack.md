# Pedindo o GitHub Student Developer Pack

Notas de um teste feito em 13/11/2026, seguindo passo a passo o guia usado no projeto DevOps Azure IFPR. O GitHub muda os menus com frequência, então confira a data. Se algo abaixo estiver diferente quando você tentar, abra uma issue.

## Caminhos atuais no GitHub

| Para fazer | Onde fica |
|---|---|
| Ativar a verificação em duas etapas (2FA) | Settings → Password and authentication |
| Conferir o nome do perfil | Settings → Public profile → Name |
| Preencher os dados de cobrança | Settings → Billing and licensing → Payment information ([link](https://github.com/settings/billing/payment_information)) |
| Pedir o benefício e acompanhar o pedido | Settings → Billing and licensing → Education benefits ([link](https://github.com/settings/education/benefits)) |
| Adicionar o e-mail da instituição | Settings → Emails → Add email address |

## Onde as pessoas costumam travar

**O menu "Plans and usage" não existe mais.** Muitos tutoriais ainda citam esse nome. O quadro "Billing information" agora fica em Payment information.

**Links antigos caem na tela errada.** O endereço `github.com/settings/billing/summary#education-benefits` abre a tela Overview, que não tem o botão "Start an application". Use o link de Education benefits da tabela acima.

**O formulário de cobrança pede mais que o nome.** Address, City e Country/Region também são obrigatórios. Depois de preencher, clique em "Save billing information". Não é preciso cadastrar cartão.

**Cadastre o e-mail institucional antes de pedir.** Quando outros alunos da mesma instituição já foram aprovados com e-mail acadêmico, o GitHub passa a exigir um. Adicione o seu (no IFPR, o `@estudantes.ifpr.edu.br`) e confirme pelo link que chega na caixa de entrada antes de abrir o pedido.

**Depois de enviar, o resultado sai em Education benefits.** Quando o pedido é aprovado, aparece "Coupon applied" com a data de validade. A análise pode levar até 72 horas.

## O que este teste não cobriu

A conta usada já tinha o benefício aprovado, então não deu para enviar um pedido novo do começo ao fim. O envio de comprovante e a verificação por câmera ou localização ficaram de fora. Se você passar por essa parte e algo for diferente, conte numa issue que eu atualizo esta página.
